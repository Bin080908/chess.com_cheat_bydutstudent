# Chess Coach (chess.com)

Tiện ích Chrome Manifest V3. Stockfish 10 WASM chạy local trong offscreen document. Overlay mũi tên + HUD nước tốt nhất trên bàn chess.com. Màu quân lấy từ hướng bàn (lật = đen).

## Cài vào Chrome

1. Mở `chrome://extensions`
2. Bật **Developer mode**
3. **Load unpacked** → chọn thư mục `C:\Users\Hoangviet\chess-best-move`
4. Vào chess.com (play vs computer / puzzles / phân tích), bấm icon tiện ích để chỉnh độ sâu
